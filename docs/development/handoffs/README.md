# Session handoffs

Create a handoff when pausing partial work or finishing a stage. Use
`YYYY-MM-DD-stage-NN-short-topic.md`; add a suffix if multiple checkpoints would
collide. Start from [the template](../templates/handoff.md).

Link the latest relevant handoff from `status.md` and the stage document. Include
the exact next action, current branch, intended modified files, verification
performed, and any blocker. Distinguish staged/committed/pushed work accurately.

Use relative paths and synthetic examples. Do not paste credentials, private
conversations, personal data, or full unreviewed terminal logs into this public
repository. No implementation handoffs exist yet.
